# NORTHFIELD ACADEMY

A polished, responsive multi-page school and college website concept.

## Pages
- Home (`index.html`)
- About (`about.html`)
- Academics (`academics.html`)
- Admissions (`admissions.html`)
- Notices & News (`notices.html`)
- Contact (`contact.html`)

## Included interactions
- Responsive mobile navigation
- Light/dark theme toggle (saved locally)
- Academic programme filters
- Notice and event filters
- Click-to-expand image gallery
- Admissions and contact demo forms with local confirmation
- FAQ accordions
- Scroll reveal effects

## Run
Extract the project and open `index.html` in a modern browser. No build tools are required.

## Important demo notes
Northfield Academy is a fictional portfolio concept. School history, programmes, testimonials (if added), campus imagery, events and notices are illustrative. Forms do not transmit or store information. Photography and Google Fonts are loaded from remote services and require an internet connection.
